Política de privacidad

Última actualización: 11 de noviembre de 2026

Esta política explica cómo la herramienta de publicación de Detrás del Botón (la "aplicación") usa la información a la que accede.

Quién usa la aplicación

La aplicación es de uso interno: solo la usa el equipo de Detrás del Botón para administrar sus propias cuentas. No está abierta al público ni recopila datos de visitantes o seguidores.

Qué datos usa

  • YouTube (Google): con tu autorización, la aplicación sube videos a nuestro propio canal y publica comentarios en nuestros propios videos, usando la API de YouTube Data. Solo guarda el token de acceso necesario para hacerlo, en el equipo del propietario.
  • Facebook e Instagram (Meta): la aplicación publica reels y comentarios en nuestras propias páginas y cuentas.

No se recopilan, venden ni comparten datos personales de terceros. No se usan datos para publicidad.

Servicios de Google

El uso de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. La aplicación también usa los Servicios de API de YouTube; al usarla aceptas los Términos de servicio de YouTube y la Política de privacidad de Google.

Cómo revocar el acceso

Puedes retirar el acceso de la aplicación a tu cuenta de Google en cualquier momento desde myaccount.google.com/permissions. Al revocarlo, el token guardado deja de funcionar.

Seguridad y conservación

Los tokens se guardan solo en el equipo del propietario y se eliminan al revocar el acceso o dejar de usar la aplicación.

Contacto

Para cualquier duda sobre esta política, escríbenos por mensaje directo en nuestras redes sociales de Detrás del Botón.
